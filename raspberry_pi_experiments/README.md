# זיהוי סרטנים חי על Raspberry Pi 5 – הדגמה על הרובוט (נובמבר 2026)

לניסים ונדב. התיקייה עומדת בפני עצמה: מעתיקים אותה כמו שהיא לפאי, ומריצים.

מצלמת USB → מודל YOLO (ONNX, על ה-CPU של הפאי) → ספירה וצפיפות של סרטנים בכל פריים,
והקלטה מלאה של כל הסשן.

## מה צריך

- Raspberry Pi 5 עם Raspberry Pi OS 64-bit (Bookworm)
- המצלמה התת-מימית מחוברת ליציאת USB 3 (הכחולה)
- אינטרנט, רק להתקנה בפעם הראשונה

## פעם ראשונה – התקנה (בערך 10 דקות)

```bash
cd 2026-11_pi5_robot_demo
bash setup_pi5.sh
```

בסוף ההתקנה יופיע `Model OK - X FPS`.

## יום שלישי – שני ניסויים

**ניסוי 1, על סרטון סרטנים מוקלט (בלי מצלמה, 1–3 דקות):**

```bash
./test1_video.sh
```

הניסוי בודק שהמודל רץ על הפאי ומזהה סרטנים, ובאיזו מהירות. הסרטון הוא קטע של 60 שניות מבריכה, ונמצא בתיקייה `test_video/`.

**ניסוי 2, מצלמה חיה (5 דקות, נעצר לבד):**

```bash
./check_camera.sh
./test2_camera.sh        # או ./test2_camera.sh 1 אם המצלמה היא 1
```

הניסוי בודק שהמצלמה, ההקלטה והקבצים עובדים על הפאי. לא צריך סרטנים: אם לא יזוהה כלום, זה בסדר.

**מה להחזיר לטאיר:**
- את התיקיות `runs_test1/` ו-`runs_test2/`.
- את `camera_test.jpg`.
- צילום מסך של המסוף.

## לפני כל הרצה – בדיקת מצלמה

```bash
./check_camera.sh
```

הסקריפט מציג אילו מצלמות מחוברות ושומר תמונה אחת: `camera_test.jpg`.
אם מופיע `Could not open camera 0`, נסו `./check_camera.sh 1`, ואז הריצו עם `./run.sh 1`.

## הרצה

```bash
./run.sh                 # רץ עד Ctrl+C
MINUTES=15 ./run.sh      # נעצר לבד אחרי 15 דקות
```

| מצב | פקודה |
|---|---|
| מצלמה אחרת | `./run.sh 1` |
| עם חלון וידאו (רק כשמחובר מסך) | `SHOW=1 ./run.sh` |
| על סרטון מוקלט במקום מצלמה | `./run.sh video.mp4` |

כל 5 שניות מודפסת שורת מצב, למשל:

```
[   35.0s] frames=160  FPS=4.6  prawns=3  density=2.4
```

- `prawns`: כמה סרטנים זוהו בפריים הנוכחי.
- `density`: ממוצע הספירה ב-10 השניות האחרונות.

**עצירה:** Ctrl+C, או `kill`, או עצירה מ-systemd. בכל אחת מהדרכים ההקלטה נסגרת כמו שצריך.

## מה נשמר

כל הרצה נשמרת בתיקייה `runs/<תאריך_שעה>/`:

| קובץ | מה יש בו |
|---|---|
| `raw.mp4` | הווידאו הנקי מהמצלמה (לתיוג בהמשך) |
| `annotated.mp4` | הווידאו עם המלבנים, הספירה והצפיפות |
| `per_frame.csv` | שורה לכל פריים: זמן, ספירה, צפיפות, אורך ממוצע, FPS |
| `detections.csv` | שורה לכל סרטן שזוהה: מיקום, ביטחון, 4 נקודות מפתח, אורכים בפיקסלים |
| `status.json` | הספירה והצפיפות האחרונות. מתעדכן כל שנייה, ומשם המזין יקרא |
| `summary.json` | סיכום ההרצה: הגדרות, מצלמה, FPS ממוצע, ספירות |
| `snapshots/` | תמונה מסומנת כל 10 שניות |

**בסוף יום הניסוי:** להעתיק את כל התיקייה `runs/` לטאיר.

## הערות

- **מהירות:** צפוי בערך 4–6 FPS על הפאי. זה מספיק לצפיפות.
- **אורכים:** בינתיים רק בפיקסלים. כיול למילימטרים יגיע בהמשך.
- **מודל:** `prawn_yolo11n_pose_v0.1`, מיוצא ל-ONNX בגודל 416. המודל אומן על צילומי GoPro, ולכן על המצלמה החדשה הזיהוי עלול להיות חלש יותר. ההקלטות מהיום הזה ישמשו לשיפור שלו.
- **בעיות:** לשלוח לטאיר את הפלט של `./check_camera.sh` ואת השורות האחרונות מהמסוף.
